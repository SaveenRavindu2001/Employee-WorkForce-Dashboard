# Employee-WorkForce-Dashboard
Interactive Employee Workforce Dashboard showcasing key HR metrics, employee attrition, departmental headcount, performance ratings, workforce diversity, and monthly trends. Includes dynamic filters for department, location, job level, year, and month to support data-driven decision-making.

## Project Objectives
- Analyze employee workforce data and key HR metrics.
- Monitor employee attrition and retention rates.
- Evaluate employee performance and tenure.
- Compare headcount across departments and locations.
- Identify workforce diversity and monthly employment trends.
- Support data-driven HR decision-making.

## Questions (KPI's)

- What is the total number of employees?
- How many employees are currently active?
- What is the employee attrition rate?
- What is the average employee tenure?
- What is the gender diversity percentage?
- Which department has the highest headcount?
- Which department has the highest attrition rate?
- How does employee headcount change monthly?
- What is the distribution of employee performance ratings?
- Which location has the highest number of employees?

## Process

- Collected and cleaned employee workforce data.
- Organized data by department, location, job level, and employment status.
- Created Pivot Tables to summarize key HR metrics.
- Calculated KPIs such as total employees, attrition rate, and average tenure.
- Created charts to visualize workforce trends and performance.
- Designed an interactive Excel dashboard using slicers.
- Applied formatting and dashboard navigation for better user experience.
